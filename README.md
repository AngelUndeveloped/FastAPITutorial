# FastAPI Learning Repo

This repository is for learning and experimenting with [FastAPI](https://fastapi.tiangolo.com/).

## How to Use

1. **Install dependencies:**

   ```bash
   pip install .
   ```

2. **Run the example app:**

   ```bash
   python main.py
   ```

## Files

- `main.py` — Main script for running FastAPI examples.
- `pyproject.toml` — Project configuration and dependencies.
